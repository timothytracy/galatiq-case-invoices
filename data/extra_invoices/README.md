# Extra invoices

The unseen check. Not part of the 20 sample files. The default `scripts/eval.py` scores `data/invoices/` against `data/answer_key.json`. Score this directory with the extra key:

```bash
python3 scripts/eval.py --invoices data/extra_invoices --answer-key data/extra_answer_key.json
```

The labels, the PR #5 keep/drop list, and the forced-failure note are in [docs/EXTRA_ANSWER_KEY.md](../../docs/EXTRA_ANSWER_KEY.md). The machine-readable copy is `data/extra_answer_key.json`.

`invoice_2107.pdf` is generated by `generate_pdf.py` (stdlib text layer; the source lines are in that script). `invoice_2001.pdf` is the file from PR #5; its text is copied in the answer-key doc.
